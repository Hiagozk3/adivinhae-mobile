#  Adivinhaê - Jogo de Adivinhação (Mobile)

Um jogo casual de lógica e raciocínio desenvolvido em Python, onde o jogador precisa descobrir o número secreto usando dicas e um contador de tentativas.

##  A História do Projeto (De Desktop para Mobile)

Este projeto marca uma etapa importante no meu desenvolvimento profissional. Ele nasceu originalmente como uma avaliação acadêmica (A3) do curso de Análise e Desenvolvimento de Sistemas (UniFG), focado em interfaces desktop utilizando a biblioteca *Tkinter*.

Para desafiar meus conhecimentos e entender o ecossistema de desenvolvimento mobile, decidi evoluir o projeto por conta própria: refatorei todo o código, adaptei a lógica para telas sensíveis ao toque utilizando o framework *Kivy*, e realizei o processo de compilação e empacotamento para Android.

##  Tecnologias e Ferramentas
* *Linguagem:* Python
* *Interface Gráfica e Mobile:* Kivy
* *Compilação e Empacotamento:* Buildozer (executado em ambiente Linux via Google Colab)
* *Formatos Gerados:* .apk (distribuição direta) e .aab (lojas oficiais)
